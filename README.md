# Michelson Interferometer Simulation

[English](#english) | [中文版](#中文版)

## English
A physical optics simulation and Zemax engineering workflow framework for a Michelson Interferometer, developed in a pure Python environment.

**Core Features:**
- **Python Physical Simulation**: Generated realistic 2D interference fringes (tilt/defocus) and 3D wavefront phase maps using Numpy and Matplotlib.
- **Zemax Double-Mode Workflow**: Provided sequential mode OPD optimization strategies and non-sequential (NSC) coherent detector setups.
- **Engineering Risk Analysis**: Analyzed coherence length limits and tolerance budgets for He-Ne (632.8nm) laser systems.
- **Automated Reporting**: Auto-generated a 16-page bilingual HTML/PDF technical report with perfect pagination.

*(Note: Zemax parts are theoretical guidance. Python parts are real physical simulations.)*

## 中文版
迈克尔逊干涉仪计量系统建模与波前分析。在无 Zemax 商业授权环境下，基于纯 Python 实现的物理光学仿真与 Zemax 工程实施双线框架。

- **自动化交付**：编写自动化脚本，直接生成 16 页双语 HTML/PDF 技术报告。
